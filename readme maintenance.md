# README 维护规范（readme maintenance）

更新日期：2026-04-08

## 1. 维护目标

- 保持 `README.md` 与仓库当前结构一致。
- 让新读者在 1 分钟内了解仓库用途、目录、使用方式。
- 在每次内容更新后记录更新时间。

## 2. 必须维护的内容

每次维护 `README.md` 时，至少检查并更新以下内容：

- 项目简介是否准确。
- 目录结构是否与当前仓库一致（顶层与关键子目录）。
- 关键模块说明是否过时（Assignment、Lab、Quiz、lecture 等）。
- 构建/运行方式是否仍可执行。
- 文末或文首的“最后更新日期”是否刷新。

## 3. 更新日期规则

- 在 `README.md` 顶部保留一行：`最后更新：YYYY-MM-DD`。
- 任何实质性改动（目录、说明、命令、学习进度）都需要更新日期。
- 仅修正错别字时可不更新日期，但建议仍更新以便追踪。

## 4. 推荐维护流程

1. 先查看当前仓库目录结构。
2. 对照 `README.md` 检查差异。
3. 更新目录树与说明文本。
4. 验证命令是否与实际路径匹配。
5. 更新“最后更新”日期。

## 5. 内容风格约定

- 使用简洁中文描述，避免冗长段落。
- 目录树优先展示关键层级，不必穷举所有文件。
- 使用 Markdown 代码块展示命令。
- 明确注明“学习资料，仅供参考”。
