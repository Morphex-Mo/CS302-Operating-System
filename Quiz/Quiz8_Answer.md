# Quiz 8

## 第一题：Priority Scheduling 与 CFS

**正确选项：A、B、D、E**

- A：很多优先级调度中，较小的优先级数字表示更高优先级。
- B：低优先级进程长期得不到运行会饥饿，aging 可逐步提高其优先级。
- C：CFS 不为所有任务使用固定时间片，而是按权重和虚拟运行时间分配。
- D：CFS 选择 `vruntime` 最小的任务运行。
- E：同 nice 值下，I/O-bound 任务实际运行少，`vruntime` 往往较低，更容易被调度。

## 第二题：RR 与 SJF

**正确选项：A、C、E**

- A：非抢占式 SJF 通常比 RR 有更小的平均等待时间。
- B：RR 的平均周转时间通常不如抢占式 SJF。
- C：RR 因时间片轮转会带来更多上下文切换。
- D：抢占式 SJF/SRTF 通常可进一步降低平均等待时间。
- E：RR 虽然平均等待和周转时间可能较差，但响应性更好。

---

## 第三题：Race Condition

**正确选项：A、B、D**

- A：多个进程/线程并发访问共享对象时可能形成竞争条件。
- B：竞争条件的结果依赖共享资源访问的具体顺序。
- C：竞争条件通常难以复现和调试，并不无害。
- D：即使 99% 执行都正常，少量错误交错仍可能产生错误结果。
- E：单核系统也可能因中断或上下文切换产生竞争条件。

---

## 第四题：Critical Section 的正确性条件

**正确选项：A、C、D**

- A：互斥是基本要求，同一时刻不能有两个进程处于相关临界区。
- B：优先级继承可解决 priority inversion，但不是临界区正确性的基本三条件之一。
- C：bounded waiting 要求等待进程不会被无限期插队。
- D：progress 要求无人处于临界区时，想进入的进程最终能有一个成功。
- E：deadlock freedom 常是期望性质，但经典临界区问题的三项基本条件是互斥、进展、有限等待。

---

## 第五题：Spin-based Locks 与 Sleep-based Locks

**正确选项：C、D**

- A：短等待更适合自旋锁；睡眠锁更适合长等待。
- B：关中断不能解决多核上其他 CPU 同时访问的问题。
- C：睡眠锁通常需要内核把等待进程阻塞/唤醒。
- D：自旋锁忙等浪费 CPU；睡眠锁可让 CPU 运行其他进程。
- E：Peterson 算法使用忙等，是 spin-based 思想，不是 sleep-based lock。
